# Application icon

`icon.png` is the canonical full-resolution artwork: the jade folder with an
enclosed, **filled** Greek tau (#1553), engraved into the folder (#1732). Its
SHA-256 is
`475bd2e647c076512db2fec2f568957e6343cb9f58c3e9e623865121fd3360f4`.

Never hand-edit the binaries here: every icon is generated by the two scripts
below. `icon.svg` and `material-style.png` are historical artwork, not
generator inputs.

## `fill_tau.py`: `icon-aperture.png` → `icon.png`

`icon-aperture.png` is the exact user-approved imagegen preview from issue
#1231 (SHA-256
`7cc37847b569050f2a065f5309caee557b817a4f1828d8d3105d69399464ac89`), in which
the tau is a transparent aperture. That artwork refined the #1000 design by
filling the diagonal opening to the right of the tau with the folder surface.
#1553 asked for the tau itself to be filled: as an aperture it showed whatever
lay behind the icon (black on dark taskbars). The script floods the enclosed
transparent region and composites the folder's antialiased edge over it, so
no halo remains.

The fill is engraved rather than flat (#1732): a vertical gradient from
near-white at the top of the tau to the folder tab's mint at its foot, with a
soft inner shadow falling from the tau's top edge (the folder's own coverage,
dropped and blurred) so the letter reads as cut into the folder. The shadow is
painted on the fill beneath the folder art, so it can only appear inside the
tau.

## `gen_icons.py`: `icon.png` → every platform asset

`gen_icons.py` regenerates the desktop PNG sizes, Windows Store logos, Android
and iOS assets (through `tauri icon`), the ICO, the ICNS, and the application
and showcase browser favicons (`static/favicon.png`, `website/favicon.png`).
Tauri's generated `icon.png` is intentionally discarded so the canonical
artwork remains intact.

From the repository root, after installing the locked Bun dependencies, run:

```sh
uv run src-tauri/icons/fill_tau.py   # only when icon-aperture.png or the engraving changes
uv run src-tauri/icons/gen_icons.py
```

Both scripts declare their Python dependencies inline (Pillow and numpy;
`gen_icons.py` also needs scipy), so `uv run` needs no environment setup. Both
are deterministic: rerunning them on unchanged inputs reproduces the committed
bytes.

### Linux, Windows, mobile: the standalone folder

Linux PNGs, the Windows ICO and Store logos keep the standalone folder with
transparency outside its silhouette: those platforms do not apply a squircle
mask, so a filled tile would look like a sticker there. The Windows ICO no
longer enlarges the glyph (`ICO_CONTENT_SCALE = 1.0`, was 1.11): the zoom
stretched the folder to ~96% of each frame, so it read oversized on Windows
(#1553). The folder now spans ~86% of the frame, close to the Windows 28/32
icon keyline. Mobile backgrounds follow
[Tauri's platform conventions](https://v2.tauri.app/develop/icons/); iOS
AppIcon PNGs use RGB encoding without an alpha channel.

### macOS: the raised folder squircle (`icon.icns` only)

Since macOS 26 the Dock and Finder put legacy ICNS art that does not fill
Apple's squircle onto a grey tile (#1640): the transparent standalone folder
became a shrunken folder on a grey backing. `icon.icns` is therefore drawn as
an opaque "raised folder squircle":

- The folder art fills a superellipse tile on Apple's macOS icon grid: a
  1024 canvas with an 824 tile centred on it, exponent 5 (a close
  approximation of Apple's continuous corner). Every face, and the tab's top,
  runs a few pixels under the tile edge and is clipped by it; the chamfered
  bottom corners continue the nearest folder face.
- The notch beside the folder tab, where the standalone folder is
  see-through, shows a deep-teal tile, so the tab still reads as a tab.
- The edge is a rounded rim lit from above, shaded from the normals of a
  quarter-round height field rather than drawn as a stroke, so the tile reads
  as raised, not bordered.
- The canvas outside the superellipse stays fully transparent, and there is no
  baked drop shadow: macOS sizes and shadows the tile itself.

Alternatives that were rejected:

- **Shrinking the folder into a translucent margin** (a frosted "glass rim"
  variant at 88% of the tile): macOS ignores translucent margins when it
  sizes the icon, so the folder simply looked smaller, and worse.
- **Icon Composer** (an `.icon` file compiled into `Assets.car`, referenced by
  `CFBundleIconName`): it needs Xcode 26's `actool` at build time. Requiring
  Xcode 26 just to build the icon is too heavy for this project's
  cross-platform build; an opaque squircle ICNS is what macOS 26 renders
  without a backing tile and needs only Python.

### Verifying the macOS icon by eye

Finder and the Dock cache icons aggressively, so check the rendered result
against a throwaway copy of the app on a Mac:

```sh
cp -R /Applications/tauri-explorer.app /tmp/IconCheck.app
cp src-tauri/icons/icon.icns /tmp/IconCheck.app/Contents/Resources/icon.icns
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /tmp/IconCheck.app
swift -e 'import AppKit
let icon = NSWorkspace.shared.icon(forFile: "/tmp/IconCheck.app")
icon.size = NSSize(width: 512, height: 512)
let rep = NSBitmapImageRep(data: icon.tiffRepresentation!)!
try! rep.representation(using: .png, properties: [:])!.write(to: URL(fileURLWithPath: "/tmp/icon-check.png"))'
```

Use an absolute path with `icon(forFile:)`: a relative path silently returns
the generic application icon. The rendered PNG must show the squircle with no
grey tile behind it. Unregister the copy afterwards (`lsregister -u`) and
delete it.

## Tests

`tests/app-icon.test.ts` decodes the generated files with `node:zlib` (no image
dependency) and checks: the tau is filled (no enclosed transparent region);
this README's SHA-256 matches `icon.png`; the ICO scale bounds and 256px
frame margin; the ICNS `ic10` (1024px) frame is an opaque superellipse tile on
Apple's grid (transparent outside it, fully opaque inside, an ~824px tile
centred on the canvas, the notch filled); and `128x128.png`, the 256px ICO
frame and `icon.png` remain the standalone folder (transparent corners and a
see-through notch). Regenerate the assets and update the SHA-256 here together.
